# EduHub - Chapter 2: Refactoring

**Course:** IN4211 - Phát triển phần mềm hướng đối tượng

## Overview

This repository contains the Chapter 2 assignment for refactoring the EduHub application.

## Objectives

- Analyze SOLID principle violations.
- Refactor classes to depend on interfaces.
- Apply Factory, Decorator, Strategy, and Observer design patterns.
- Write at least six xUnit unit tests using Arrange-Act-Assert.
- Practice Git branching, commits, rebasing, and pull requests.

## Technology

- .NET 10
- C#
- xUnit

## Status

Work in progress. The implementation will be updated as the assignment is completed.
